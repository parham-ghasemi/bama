## ویژگی‌ها

پلتفرم ما یک **مارکت‌پلیس کامل برای اجاره ویلا** است که با تکنولوژی مدرن **MERN** ساخته شده.

این سیستم تجربه‌ای روان و جذاب برای **جستجو، رزرو و مدیریت ویلاها** فراهم می‌کند و در عین حال به ادمین ابزارهای قدرتمندی برای **مدیریت کارآمد اکوسیستم** می‌دهد.

### تجربه کاربری

- **صفحه فرود جذاب**
  صفحه اصلی زیبا با یک هدر منحصربه‌فرد و نوار جستجوی پیشرفته.
  شامل ردیف‌های پویا از تصاویر، کارت‌ها و بخش‌های متنی که برای جذب کاربران و نمایش مقصدهای برگزیده طراحی شده‌اند.
- **سیستم جستجوی قدرتمند**
  یک نوار جستجوی هوشمند و پیشرفته همراه با صفحه نتایج اختصاصی برای فیلتر دقیق و کشف ویلاها.
- **صفحه جزئیات ویلا**
  هر ویلا یک صفحه توضیحات کامل شامل:
  - تصاویر باکیفیت
  - امکانات و قیمت‌گذاری دقیق
  - **بخش نظرات** برای بازخورد کاربران
  - **جمع‌بندی هوشمند نظرات با هوش مصنوعی** برای ارائه خلاصه‌ای سریع از تجربه مهمان‌ها
- **رزرو و ثبت‌نام اقامت**
  کاربران می‌توانند ویلا رزرو کنند، اقامت‌های آینده را پیگیری کنند و تاریخچه رزروهای خود را مشاهده نمایند.

### حساب کاربری و داشبورد

- **صفحه پروفایل شخصی**
  هر کاربر یک داشبورد اختصاصی دارد که در آن می‌تواند:
  - اطلاعات شخصی را ویرایش کند
  - **ویلاهای پسندیده‌شده** را مدیریت کند
  - **رزروهای گذشته و جاری** را مشاهده کند
  - موجودی **کیف‌پول** را بررسی و شارژ کند
- **مدیریت میزبان**
  کاربران می‌توانند ویلای خود را برای درج در پلتفرم ثبت کنند. پس از تأیید ادمین، این ویلاها برای سایر کاربران قابل رزرو خواهند بود.

### هوش مصنوعی و خودکارسازی‌ها

- **خلاصه‌ساز هوشمند نظرات**
  به‌صورت خودکار برای هر ویلا خلاصه‌ای از نظرات کاربران تولید می‌شود تا کاربر سریع‌تر تصمیم‌گیری کند و اعتماد بیشتری داشته باشد.

### صفحات اضافی

- **صفحه سوالات متداول (FAQ)**
  بخشی اختصاصی برای پاسخ به سوالات رایج کاربران.
- **صفحات رزرو و تاریخچه**
  جداول کامل برای مشاهده تمام رزروهای فعال و تکمیل‌شده.

### داشبورد ادمین

یک پنل جامع برای ادمین با ابزارهای مدیریتی پیشرفته شامل:

- **مدیریت کاربران و ویلاها** – تأیید ویلاها، مدیریت میزبان‌ها و نظارت روی محتوا
- **آنالیزها و آمار** – نمایش کلی رزروها، نمودارهای درآمد و شاخص‌های کلیدی
- **ردیابی درآمدها** – صفحات اختصاصی برای مدیریت تراکنش‌ها و درآمد پلتفرم
- **بینش‌های رزرو** – نمایش کلی و جزئی رزروها
- **سیستم تیکت‌ها** – صفحه پشتیبانی برای رسیدگی به درخواست‌ها و مشکلات کاربران

## نحوه اجرا

قبل از شروع، مطمئن شوید موارد زیر روی سیستم شما نصب یا اجرا می‌شوند:

- Node.js (نسخه LTS پیشنهاد می‌شود)
- MongoDB (به‌صورت محلی یا از راه دور)

### 1. نصب وابستگی‌ها

به فولدرهای `front` و `back` بروید و پکیج‌های لازم را نصب کنید:

```bash
cd front
npm i

cd ../back
npm i
```

### 2. اجرای سرورهای توسعه

فرانت‌اند و بک‌اند را در ترمینال‌های جداگانه اجرا کنید:

```bash
# Front-end
cd front
npm run dev

# Back-end
cd back
npm run dev
```

### 3. مشاهده اپلیکیشن

پس از شروع فرانت‌اند، Vite یک آدرس محلی (معمولاً `http://localhost:5173`) نمایش می‌دهد.

با باز کردن آن در مرورگر، می‌توانید اپلیکیشن را مشاهده کنید.

## وضعیت پروژه

این پروژه در حال حاضر **حدود ۹۰٪ تکمیل شده** و بسیار نزدیک به نسخه نهایی است. ساختار اصلی، قابلیت‌های کلیدی و کل جریان‌های کاربری/ادمین تکمیل شده‌اند. تنها چند ویژگی نهایی و جزئیات باقی مانده تا پلتفرم کاملاً آماده انتشار شود.

### کارهای باقی‌مانده

- **سیستم تیکت کاربران**
  پیاده‌سازی صفحه‌ای برای ارسال درخواست‌های کاربران به پنل پشتیبانی ادمین.
- **تکمیل بخش مالی ادمین**
  تکمیل بخش‌های باقی‌مانده مدیریت مالی و درآمدی پنل ادمین.
- **سیستم امتیازدهی باما**
  تکمیل سیستم گیمیفای‌شده‌ای که کاربران با هر رزرو ویلا امتیاز دریافت می‌کنند.
  این امتیازها بعدها قابل تبدیل به تخفیف برای رزروهای بعدی خواهند بود.
- **بهبودهای UI/UX**
  - افزودن تصاویر باقی‌مانده به صفحه فرود
  - رفع لینک‌های اشتباه یا خراب
  - بهبودهای ظاهری و یکپارچه‌سازی بخش‌های مختلف

پس از انجام این موارد، پلتفرم کاملاً آماده انتشار خواهد بود.

### یادداشت توسعه‌دهنده

پیشرفت پروژه اخیراً کندتر شده زیرا در حال حاضر درگیر یک **قطع اینترنت** هستم که بیش از یک ماه مانع کار روی پروژه شده. به‌محض برقراری اتصال پایدار، توسعه از سر گرفته خواهد شد.
