## Features

Our platform is a full‑featured **villa rental marketplace** built with the modern **MERN** stack.

It provides users with an elegant experience to **explore, book, and manage villas**, while giving admins powerful tools to **manage the ecosystem** efficiently.

### User Experience

- **Captivating Landing Page**
    
	A beautifully designed homepage featuring a unique header and an advanced search bar.
    
    Includes dynamic rows of images, cards, and text sections crafted to engage users and highlight featured destinations.
    
- **Powerful Search System**
    
    An intelligent, advanced search bar with a dedicated results page for precise filtering and discovery.
    
- **Villa Details Page**
    
    Each villa has a feature‑rich description page with:
    
    - High-quality images
    - Detailed amenities and pricing
    - **Comment section** for user feedback
    - **AI‑powered comment summary** giving quick insights into what guests are saying
- **Reservations & Bookings**
    
    Users can seamlessly book villas, track upcoming stays, and review their booking history.
    

### User Account & Dashboard

- **Personal Profile Page**
    
    Every user has a personalized dashboard where they can:
    
    - Edit personal data
    - View and manage **liked villas**
    - Track **past and current bookings**
    - Monitor and deposit money into their **wallet**
- **Host Management**
    
    Users can submit their own villas for listing. Once approved by the admin, these villas become available for rental to other users.
    

### AI & Automations

- **AI Comment Summaries**Automatically generate smart summaries for each villa’s reviews to improve browsing efficiency and user trust.

### Additional Pages

- **FAQ Page**
    
    A dedicated FAQ section to assist users with common questions.
    
- **Reservations & History Pages**
    
    Comprehensive tables and views for viewing all active and completed bookings.
    

### Admin Dashboard

An all‑in‑one admin panel equipped with advanced management tools, including:

- **User & Villa Management** – Approve listings, manage hosts, and moderate content
- **Analytics & Statistics** – Overview of bookings, revenue charts, and key metrics
- **Earnings & Income Tracking** – Dedicated pages to view platform income and manage financial data
- **Booking Insights** – Overview and detailed booking management panels
- **Tickets System** – A support page allowing admins to handle user requests and issues

## How to Run

Before starting, ensure you have the following installed and running on your system:

- Node.js (LTS recommended)
- MongoDB (running locally or connected to a remote instance)

### 1. Install dependencies

Navigate into both the `front` and `back` folders and install the required packages:
```bash
cd front
npm i

cd ../back
npm i
```
### 2. Start the development servers

Run the front‑end and back‑end in separate terminals:
```bash
# Front-end
cd front
npm run dev

# Back-end
cd back
npm run dev

```
### 3. View the application

After the front-end starts, Vite will show a local development URL (usually something like `http://localhost:5173`).

Open it in your browser to view the app.
